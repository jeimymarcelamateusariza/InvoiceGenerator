# Skill Registry

- **sdd-init**: Initialize SDD context, testing capabilities, registry, and persistence.
- **sdd-explore**: Explore architecture, project structure, and requirements before changes.
- **sdd-new**: Create new OpenSpec change proposals and specifications.
- **sdd-apply**: Execute change implementation tasks according to specification.
- **sdd-verify**: Validate implementation against specifications, running tests and linters.
